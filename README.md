# Personal-Portfolio-Website

Personal Portfolio Website

A personal portfolio website showcasing my technical skills, projects, achievements, education, and professional profiles.

About the Project

This portfolio serves as my personal digital space to present my journey as a Computer Science student, highlight my work, and connect with others.

Features

- Personal introduction and profile
- Technical skills showcase
- Projects and achievements
- Education details
- GitHub, LinkedIn, and LeetCode profile links
- Resume download option
- Responsive user interface

Technologies & Tools

- HTML5
- CSS3
- JavaScript
- Claude AI
